# ScholarPulse - 學術與文獻論文選讀檢索 AI Agent
學術與文獻論文選讀檢索 AI Agent - 中央大學 AI Agent 課程專案

## 專案簡介
ScholarPulse 是一款專為大專院校學生與研究人員設計的**學術文獻檢索與論文研讀 AI 助理**。本專案建構於 Coze 平台，結合大語言模型的理解能力與 RAG（檢索增強生成）技術，旨在協助使用者高效閱讀論文、自動萃取研究方法與重點成果，並進行結構化的文獻整理。

---

## 應用場景與目標痛點

### 1. 解決痛點
- **閱讀效率低**：長篇英文論文包含大量背景與前置作業，需耗費許多時間才能抓到 Core Methodology 與實驗數據。
- **名詞門檻高**：跨領域論文充斥專業術語與數學推導，初學者理解困難。
- **資料整理繁瑣**：撰寫期末報告或進行文獻回顧時，缺乏統一且自動化的結構化摘要工具。

### 2. 核心應用場景
- **網址解析**：貼上 [arXiv 論文連結](https://arxiv.org/abs/2201.11903)，Agent 自動擷取摘要並梳理文章結構。
- **PDF 深入研讀**：上傳指定的學術論文 PDF，針對文章細節進行精準問答與導讀。
- **結構化輸出**：自動將論文重點轉譯為標準 JSON 格式，方便直接匯入個人閱讀筆記（如 Notion、Obsidian）或研究報告中。

## Agent 功能與架構規劃

本專案遵循課程進度規劃，逐步完成以下模組建構：

- **[單元 1] LLM 模型選擇與參數配置**
  - 選用具備強大長文本理解與邏輯推理能力之模型，並微調 Temperature 參數以確保學術嚴謹度。
- **[單元 2] System Prompt 設計與 JSON 輸出**
  - 設定客觀嚴謹的「學術研究助理」角色語氣，並實現包含標題、研究方法、結論等欄位的 JSON 結構化輸出。
- **[單元 3] 記憶機制 (Memory)**
  - 透過變數（Variable）記錄使用者的研究領域偏好、摘要長度需求與慣用語言。
- **[單元 4] 專屬知識庫 (Knowledge / RAG)**
  - 上傳特定領域之論文 PDF 建立向量知識庫，提供具出處依據的精準檢索，避免 AI 產生幻覺。
- **[單元 5] Plugin-Tool 串接**
  - 串接 `browser` 工具，使 Agent 能即時爬取並解析外部論文網頁內容。
- **[單元 6~8] Chatflow 工作流與 Guardrail 防護**
  - 建立自動化意圖判斷與參數補全流程，並加入安全護欄以過濾非學術相關或不當輸入。
